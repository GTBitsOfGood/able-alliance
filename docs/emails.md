# Email

## Local

- Use `npm run email:dev` to view templates
- Saves rendered HTML files to `emails-preview/`

## Upsun

- Email uses [Upsun Fixed's SMTP proxy](https://fixed.docs.upsun.com/development/email.html)
- Sender is `GT Paratransit <noreply-paratransit@hosting.gatech.edu>`
- Upsun supplies `PLATFORM_SMTP_HOST` automatically
